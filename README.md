## 🧠 Descripción del Proyecto
Este repositorio contiene el desarrollo del Taller 5 de Arquitectura Empresarial, enfocado en el modelado de amenazas mediante el marco **STRIDE** (Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, Elevation of Privilege). 

El trabajo se divide en dos fases:
1. **Trabajo en Clase:** Análisis de un sistema de referencia (EdukIT) y documentación de un reto práctico de explotación (OWASP Juice Shop).
2. **Aplicación al Cliente Real:** Evaluación de seguridad de la arquitectura actual (AS-IS) de **Insuclínicos Ltda.**, centrado específicamente en el flujo de gestión operativa (Archivos Excel locales y WhatsApp) que soporta los pedidos y el inventario.
